## 作品について

戦国策の江戸時代の和訳。『通俗戦国策』で、自序と巻第一から巻第十八（附録）までを収める。『通俗二十一史』第 6 巻に、通俗続三国志の附録として加えられたもの。撰者は本文に記されていない。OCR の柱から付けた見出しが付く。

## 底本

- [通俗二十一史](https://dl.ndl.go.jp/pid/775963)（早稲田大学出版部・1912年）。国立国会図書館の全文テキスト（OCR）のまま

国立国会図書館デジタルコレクションの「インターネット公開（保護期間満了）」の資料です。

## 本文の作り方

国立国会図書館デジタルコレクション（インターネット公開）の全文テキスト（OCR）をそのまま収めた。1 段落が底本の 1 コマ（見開き）。校正はしていないので、振り仮名や柱の混じり、読み違いが残る。
